# Delivery operations playbook

Use this playbook to gather and record evidence before applying the
[delivery exception policy](delivery-exception-policy.md).

## Intake

- Match the ticket's order and tracking IDs to the shipment record.
- Check the customer's report time. Use evidence available at that time when replaying a case.
- Read the resolution history for the same order and issue. Check whether any refund or replacement is complete before treating the case as resolved.

## Parcel marked delivered but missing

- Start with the latest delivered scan. Check the scan time and the delivery location against the customer's account.
- If there is a photo, signature, or recipient code, note what it establishes. A recognizable parcel label alone may leave the delivery location unclear.
- When the policy calls for a carrier investigation, include the tracking ID, delivered scan, and the evidence that led to the request. Record the carrier's ticket reference when available.

## Return to sender

- Identify the last return event. Confirm that a receipt scan came from the retailer's warehouse. A carrier depot scan shows that the parcel is still with the carrier.
- After warehouse receipt, check the customer's refund or replacement request, replacement stock, and the address status.
- If a replacement needs address confirmation, request it through the support channel.

## Record and review

- Record the proposed action, refund amount, policy section, and evidence that supports the decision.
- If the proposed action requires review, hold it for a supervisor. Record the reviewer and the outcome when available.
- Check the latest case and resolution status before retrying a refund or replacement.
